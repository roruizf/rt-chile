# Política de derechos de autor

| Tipo de fuente | Ejemplos | ¿Se puede incluir en repo / notebook público? |
|---|---|---|
| Actos oficiales publicados | DS 15/2024, OGUC, Resoluciones Exentas MINVU, decretos PDA/PPA, Ley 21.305, DDU | Sí, citando fuente oficial y fecha |
| Publicaciones MINVU/DITEC | LOSCAT, láminas DITEC, comunicados | Sí, con atribución a MINVU; no alterar |
| Manuales de terceros | MRT (Instituto de la Construcción) | Solo link + resumen propio, salvo licencia expresa (verificar) |
| Normas NCh (© INN) | NCh 853, 1079, 1973, 3117, 3137, 3295-3297, 3308, 3309, 2251, 851, 3076 | **No.** Solo metadata, resumen propio, algoritmos propios y valores puntuales citados |

Las copias privadas de trabajo (para leer y redactar resúmenes propios) viven fuera del repo, en
`sources/private/` (ignorado por git) o en almacenamiento privado. Nunca se suben a un notebook compartido.
Capturas de pantalla o conversiones a markdown de una NCh siguen siendo reproducción: tampoco se publican.
